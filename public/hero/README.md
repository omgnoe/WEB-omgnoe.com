# Hero plate

Drop the header image here as `header.jpg` (or `.png` / `.webp`), then rebuild.
`lib/hero.ts` picks it up automatically; with no file present the hero falls
back to the gradient and still looks finished.

What the layout wants:

- Wide, 2400x1350 or larger (16:9).
- Dark overall. The page background is `#0a0b0c`, so the plate should sit in
  that family rather than fight it.
- The **left third close to black**: the headline and the buttons sit there and
  a scrim alone will not rescue a busy left side.
- Subject toward the centre-right.
- No text or logos in the image. The page supplies all of those.
